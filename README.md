\# Chatbot Project



\## Overview

This project builds a simple AI chatbot using Python and machine learning.



\## Technologies Used

\- Python

\- Flask

\- Scikit-learn

\- NLP



\## Features

\- Intent classification

\- Automated chatbot responses

\- Flask API server

\- Interactive chat system



\## Files

\- intents.json

\- train\_chatbot.py

\- app.py



\## How to Run



Install libraries:



pip install flask pandas scikit-learn notebook



Run chatbot:



python train\_chatbot.py



Run API server:



python app.py
